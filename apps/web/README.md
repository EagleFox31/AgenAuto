# apps/web

Application principale AgenAuto.

Elle regroupera :
- Next.js pour l'expérience publique ;
- Payload CMS comme Headless Core ;
- Payload Admin pour les opérations internes ;
- les routes publiques de catalogue, discovery et comparaison ;
- les workflows de leads ;
- les collections Payload et leurs règles d'accès.

Le bootstrap technique est suivi dans l'Issue #1.
