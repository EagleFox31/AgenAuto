# apps/web/src

Organisation du code source AgenAuto :

- `app/` — routes Next.js ;
- `collections/` — modèle persistant Payload ;
- `features/` — logique produit différenciante ;
- `access/` — RBAC ;
- `hooks/` — hooks Payload ciblés ;
- `jobs/` — tâches Payload ;
- `server/` — orchestration serveur ;
- `components/` — composants locaux ;
- `types/` — types locaux ;
- `lib/` — utilitaires techniques.

Les frontières sont documentées dans `docs/REPOSITORY_STRUCTURE.md`.
