Route group Next.js pour l'expérience publique AgenAuto.

Contiendra progressivement :
- accueil ;
- catalogue ;
- pages marques/modèles/finitions ;
- recherche ;
- comparaison ;
- dealers ;
- formulaires devis/essai.

Les pages consomment le Headless Core via la Local API Payload quand elles s'exécutent côté serveur.
