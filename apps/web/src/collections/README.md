# Payload collections

Les collections sont organisées par domaine plutôt que dans un fichier unique.

- `automotive/` : référentiel canonique véhicule ;
- `market/` : distributeurs, agences, offres, prix et disponibilité ;
- `platform/` : utilisateurs, rôles, médias, sources, imports et audit.

La séparation Canonical Vehicle / Dealer Offer reste un invariant du produit.
