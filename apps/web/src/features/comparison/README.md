# Comparison

Moteur de comparaison automobile AgenAuto.

Responsabilités :
- comparaison de 2 à 4 finitions ;
- normalisation des unités ;
- gestion explicite des valeurs inconnues ;
- regroupement des spécifications ;
- détection et mise en évidence des différences ;
- projection éventuelle des offres concessionnaires.

C'est une brique métier AgenAuto, pas une fonctionnalité générique du CMS.
