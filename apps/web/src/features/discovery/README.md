# Discovery

Logique produit de recherche et découverte.

Responsabilités :
- filtres véhicule ;
- tri et pagination ;
- projections publiques ;
- URLs partageables ;
- règles de visibilité des données partielles ;
- SEO des pages marques/modèles.

Cette logique ne doit pas être dispersée dans les composants UI ou les hooks de collections.
