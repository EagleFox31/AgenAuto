# Jobs

Tâches applicatives exécutables via Payload Jobs lorsque le besoin reste dans le périmètre TypeScript/Headless Core.

Exemples futurs :
- notifications de leads ;
- refresh contrôlé d'offres ;
- petits imports ;
- maintenance de projections ;
- tâches planifiées légères.

Un traitement lourd ou très spécialisé peut être déporté vers `services/ingestion`.
