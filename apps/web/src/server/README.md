# Server

Code serveur AgenAuto qui orchestre Payload sans exposer de dépendances techniques inutiles aux composants UI.

Exemples futurs :
- loaders/projections ;
- services applicatifs ;
- commandes métier ;
- intégration Local API Payload ;
- orchestration de transactions simples.

Les fonctions pures réutilisables restent dans `packages/automotive-domain`.
