# data/pilot

Espace de travail pour le dataset pilote AgenAuto.

Objectif initial :
- 3 à 5 distributeurs ;
- 5 à 8 marques ;
- modèles/finitions réellement commercialisés ;
- 30 à 50 spécifications comparables ;
- sources et dates d'observation traçables.

## Important

Ne pas committer de données propriétaires, personnelles ou dont les droits de réutilisation ne sont pas établis.

Les données publiées dans l'application restent gérées via Payload/PostgreSQL. Ce dossier sert aux fixtures, mappings, échantillons autorisés et documentation de préparation du dataset.
