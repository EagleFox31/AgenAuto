# data/pilot

Espace de travail pour le dataset pilote AgenAuto.

Objectif initial :
- 3 à 5 distributeurs ;
- 5 à 8 marques ;
- modèles/finitions réellement commercialisés ;
- 30 à 50 spécifications comparables ;
- sources et dates d'observation traçables.

Le périmètre courant est documenté dans `PILOT_SCOPE.md`. Le premier dataset automatisé est `sky-motors/` pour Jetour.

## Important

Ne pas committer de données propriétaires, personnelles, de contenu marketing copié, d'images ou de brochures dont les droits de réutilisation ne sont pas établis.

Les faits structurés publics peuvent servir de candidats de revue lorsqu'ils conservent URL source et date d'observation. Les données publiées dans l'application restent gérées via Payload/PostgreSQL. Ce dossier sert aux fixtures, mappings, observations structurées et documentation de préparation du dataset.
