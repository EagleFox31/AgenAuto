# packages/automotive-domain

Brique métier réutilisable contenant les concepts qui ne doivent pas dépendre directement de Next.js, Payload ou de l'UI.

Cibles futures :
- types et vocabulaires automobiles ;
- unités et conversions ;
- normalisation de spécifications ;
- helpers de comparaison ;
- règles de validation canonique ;
- fonctions pures testables.

Cette brique constitue une partie du savoir-faire AgenAuto/AppFactory.
